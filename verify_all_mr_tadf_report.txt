6. DEFINITION NOTE  (why the columns are not all the same quantity)
========================================================================================================================
  C,K,S,AA (TDA) and D,L,T,AB (TD-DFT) are true gaps  S1 - T1.
  F,H,N,P,V,X,AD,AF (USF-TDA) and G,I,O,Q,W,Y,AE,AG (XSF-TDA) are the first singlet of a
  spin-flip spectrum measured from the triplet reference state; the spin-flip spectrum
  still contains the m_s = 0 component of that triplet (it is not spin complete), so the
  number is smaller than a genuine S1 - T1 gap by the residual triplet energy:
    USF-TDA ALDA0 B3LYP       residual m_s=0 triplet - S1 = -0.302 .. +0.080 eV, mean -0.187   (34 molecules)
